# ApexPlanet Task 2 – EDA & Business Intelligence

## Project Overview
This project is part of the ApexPlanet 60-Day Data Analytics Internship. It focuses on Exploratory Data Analysis (EDA), SQL queries, and sales data analysis.

## Objectives
- Explore and understand the sales dataset.
- Perform SQL queries to answer business questions.
- Analyze sales trends and product performance.
- Create visualizations to identify useful patterns.

## Tools and Technologies
- SQL
- Python
- Pandas
- Data visualization
- Visual Studio Code

## Project Files
- `sales_data.csv` – Sales dataset.
- `sql_queries.sql` – Seven SQL business queries.
- `task2_eda.py` – Python script for exploratory data analysis.
- Query screenshots – Results of the seven SQL queries.

## SQL Analysis
The project includes seven business queries covering:
1. Total sales
2. Top five products
3. Monthly sales
4. Top sales category
5. City-wise sales
6. Gender-wise sales
7. Above-average sales

## Project Deliverables
- SQL queries and their results
- Sales dataset
- Python EDA script
- SQL output screenshots
